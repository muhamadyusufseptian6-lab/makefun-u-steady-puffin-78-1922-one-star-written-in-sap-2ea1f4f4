A houseplant leaves a one-star review of its human owner. One line, under 280 characters, written by a fern that has had enough.

## The review

> ★☆☆☆☆ One star. He waters me with leftover iced coffee, drags me to a new corner weekly for 'better vibes,' then acts betrayed when I drop a leaf. I am a fern, not a mood ring.

## How it works

`main.ts` (Node 22, stdlib only, deterministic) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else, no network, no randomness — the same grumpy fern every run.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
